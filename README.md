# FRAXEL Inmobiliaria

Proyecto académico de maestría. Página web de una sola hoja con fotografías y fichas provisionales.

## Publicación

GitHub Pages publica el contenido de la rama `main` desde `/ (root)`. Los cambios guardados en esta rama actualizan la página.

## Colaboración

Los visitantes consultan la web sin iniciar sesión. El código es público; solo el propietario y los colaboradores autorizados pueden modificar este repositorio. El propietario puede invitar programadores desde **Settings > Collaborators > Add people**. Cada persona utiliza su propia cuenta.

## Archivos

- `index.html`: contenido y estructura.
- `styles.css`: estilos generales y adaptación a pantallas.
- `hero.css`: cabecera y formulario al final.
- `app.js`: fichas, filtros, galería y menú.
- `assets/`: imágenes, logo y tipografía con su licencia.

No se requieren instalaciones ni dependencias para abrir `index.html`. Se puede usar un servidor estático local para desarrollo.

## Datos pendientes

Los precios, las características, Las fotos son provisionales. Respetar siempre los colores originales del logo de FRAXEL.

El sitio puede mantenerse publicado durante los siete días de la presentación. No hay eliminación automática programada.
